# Procedural Game Balancing Thesis

This repository contains my Honours Computer Science thesis report on procedural game balancing.

The experiment investigates how generated game content can be evaluated automatically before being accepted into a game system. I used a deterministic Super Auto Pets simulation backend so generated artifacts could be tested under repeatable conditions instead of judged only by manual inspection.

The project focused on four evaluation goals:

- Fairness: checking whether generated content creates unreasonable advantages.
- Diversity: measuring whether generated outputs meaningfully differ from each other.
- Stability: testing whether results remain consistent across repeated seeded runs.
- Safety: detecting invalid, broken, or degenerate game states.
